
# Job Application Form - CareerConnect

## Description
A multi-section job application form with validation and draft-saving functionality.

## Features
- Personal details validation
- Education details validation
- Technical skills checkboxes
- Error summary
- Success message
- Save draft
- Restore draft after refresh
- Clear saved draft

## Technologies
- HTML5
- CSS3
- JavaScript
- localStorage
