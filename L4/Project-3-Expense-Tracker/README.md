
# Expense Tracker - MoneyTrack

## Description
A personal finance tracker to manage income, expenses and available balance.

## Features
- Add income
- Add expenses
- Calculate total income
- Calculate total expenses
- Display available balance
- Filter transactions
- Delete transactions
- localStorage persistence
- Responsive design

## Technologies
- HTML5
- CSS3
- JavaScript
- localStorage
